# Auto Switch TH/EN

พิมพ์ไทย-อังกฤษ ไม่ผิดภาษาอีกต่อไป — สำหรับ Mac และ Windows

- ป้ายบอกภาษา `ไทย` / `EN` ตอนคลิกช่องพิมพ์และตอนสลับภาษา
- แปลงข้อความที่พิมพ์ผิดแป้นในปุ่มเดียว (`l;ylfu` → `สวัสดี`)
- ช่องรหัสผ่านเป็นภาษาอังกฤษเสมอ

**ดาวน์โหลดและรายละเอียด: https://autoswitch-th-en.vercel.app**
